# 📈 Stock Research Agent (KOSPI/KOSDAQ 개인용 종목 리서치 도구)

한국 코스피(KOSPI) / 코스닥(KOSDAQ) 상장 종목의 시세를 받아와서

- 이동평균, RSI, MACD, 볼린저밴드 등 기술적 지표를 계산하고
- "20일선이 60일선을 돌파", "거래량 급증" 같은 매매 시그널을 정의하고
- 과거에 그 시그널이 발생했을 때 **실제로 이후 며칠 뒤 수익률이 어땠는지** 통계를 내고
- 그 결과를 Streamlit 웹 대시보드로 보여주는

개인용 주식 리서치 프로젝트입니다.

> ⚠️ **투자 조언이 아닙니다.** 이 프로젝트가 보여주는 모든 통계는 "과거에 이런 패턴이 있었을 때
> 평균적으로 이랬다"는 과거 데이터 기반 참고 자료일 뿐이며, 미래 수익을 보장하지 않습니다.
> 투자 판단과 그 결과에 대한 책임은 본인에게 있습니다.

---

## 1. 이 프로젝트가 하는 일 (한눈에 보기)

```
[1] KOSPI/KOSDAQ 종목 목록 가져오기
        ↓
[2] 종목별 최근 5년 일봉(하루 단위 시세) 데이터 가져오기
        ↓
[3] 기술적 지표 계산 (이동평균, RSI, MACD, 볼린저밴드, 거래량평균, 52주 신고가, 모멘텀)
        ↓
[4] 매매 시그널 계산 (골든크로스, 거래량 급증, 신고가 돌파, RSI 상향돌파 등)
        ↓
[5] 각 시그널이 발생한 뒤 5/20/60거래일 후 수익률 계산 (과거 데이터로 사후 검증)
        ↓
[6] 시그널별 통계 집계 (발생횟수, 평균/중앙값 수익률, 상승확률, 큰 상승확률, 최대낙폭) → CSV 저장
        ↓
[7] Streamlit 대시보드로 종목 검색 + 차트 + 현재 시그널 + 과거 통계를 한 화면에서 확인
```

## 2. 프로젝트 구조

```
my-PJT/
├── README.md                 # 지금 보고 있는 파일
├── requirements.txt           # 필요한 파이썬 패키지 목록
├── app.py                     # ⭐ Streamlit 웹 대시보드 메인 화면 (종목 리서치)
│
├── pages/
│   └── 1_📡_종목_검색식.py     # ⭐ 종목 검색식(스크리너) 화면 - 사이드바에서 이동
│
├── src/                        # 핵심 로직 코드
│   ├── config.py               # 설정값 모음 (이동평균 기간, RSI 기간 등 전부 여기서 관리)
│   ├── data_loader.py          # 종목 목록 / 시세 데이터를 받아오고 캐싱(저장)하는 코드
│   ├── indicators.py           # 기술적 지표 계산 코드
│   ├── signals.py              # 매매 시그널 정의 코드 (단일 종목 백테스트용)
│   ├── backtest.py             # 미래 수익률 계산 + 시그널별 통계 집계 코드
│   ├── market_regime.py        # 코스피/코스닥 지수 추세(상승장/하락장) 판단 코드
│   ├── screener.py             # 종목 검색식(스크리너) 조건 정의 코드
│   ├── investor_flow.py        # 기관/외국인 순매수 거래대금 순위 조회 코드 (pykrx)
│   └── pipeline.py             # 위 과정을 한 종목에 대해 순서대로 실행해주는 코드
│
├── scripts/
│   └── run_backtest.py         # 여러 종목을 한꺼번에 분석해서 CSV로 저장하는 실행 스크립트
│
└── data/                        # 실행하면 자동으로 생성되는 데이터 저장 폴더
    ├── raw/                     # 종목별로 받아온 원본 시세 캐시 (CSV)
    └── processed/               # run_backtest.py 실행 결과 (시그널 통계 CSV)
```

**각 폴더/파일이 하는 역할을 한 문장으로 요약하면:**

| 파일 | 역할 |
|---|---|
| `src/config.py` | "이동평균은 며칠로 할지", "RSI 몇 일로 할지" 같은 숫자 설정을 모아둔 곳 |
| `src/data_loader.py` | 인터넷에서 종목 목록/시세를 받아오는 곳 (받은 건 `data/raw/`에 저장해서 재사용) |
| `src/indicators.py` | 받아온 시세로 이동평균, RSI 등 "지표"를 계산하는 곳 |
| `src/signals.py` | 지표를 보고 "오늘 매수 신호가 떴다" 같은 시그널을 판정하는 곳 (단일 종목 백테스트용) |
| `src/backtest.py` | "이 시그널이 과거에 떴을 때 진짜 수익이 났었나?"를 계산하는 곳 |
| `src/market_regime.py` | 코스피/코스닥 지수 자체가 상승장인지 하락장인지 판단하는 곳 |
| `src/screener.py` | "지금 이 조건에 맞는 종목"을 시장 전체에서 찾는 검색식(스크리너) 조건들 |
| `src/investor_flow.py` | 기관/외국인이 최근 얼마나 순매수했는지 순위를 가져오는 곳 |
| `src/pipeline.py` | 위 과정들을 한 종목에 대해 순서대로 실행해주는 조립 라인 |
| `scripts/run_backtest.py` | 여러 종목을 한꺼번에 돌려서 시장 전체 통계 CSV를 만드는 스크립트 |
| `app.py` | 종목 리서치 메인 화면 (차트 + 현재 시그널 + 과거 통계) |
| `pages/1_📡_종목_검색식.py` | 시장 전체를 스캔하는 검색식 화면 + 기관/외국인 거래대금 순위 |

## 3. 준비물

- **인터넷이 되는 컴퓨터** (Windows / Mac 모두 가능)
- **Python 3.10 이상** 설치되어 있어야 합니다.
  - 설치 여부 확인: 터미널(Mac) 또는 명령 프롬프트(Windows)를 열고 아래 명령을 입력해보세요.
    ```
    python3 --version
    ```
    (Windows에서는 `python --version` 일 수도 있습니다)
  - 설치가 안 되어 있다면 [python.org](https://www.python.org/downloads/) 에서 다운로드해서 설치하세요.
    설치할 때 **"Add Python to PATH"** 체크박스를 꼭 체크하세요.

> 💡 이 프로젝트는 실시간으로 인터넷에서 한국 증권 시세를 받아오기 때문에,
> **인터넷 연결이 되지 않는 환경(예: 사내망만 되는 샌드박스, 일부 클라우드 개발 환경)에서는
> 데이터를 받아오는 부분이 오류가 날 수 있습니다.** 이 경우 일반 인터넷이 되는 개인 PC에서
> 실행해주세요.

## 4. 처음 설치하기 (딱 한 번만 하면 됩니다)

### 4-1. 프로젝트 폴더로 이동하기

터미널(Mac) 또는 명령 프롬프트(Windows)를 열고, 이 프로젝트 폴더로 이동합니다.

```bash
cd my-PJT
```

### 4-2. 가상환경 만들기 (파이썬 패키지를 이 프로젝트 안에서만 깨끗하게 관리하기 위함)

**Mac / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (명령 프롬프트):**
```bat
python -m venv .venv
.venv\Scripts\activate
```

명령을 실행하고 나면, 터미널 맨 앞에 `(.venv)` 라는 글자가 보이면 성공입니다.
(이후 이 프로젝트 작업을 할 때마다, 새 터미널을 열 때마다 이 `activate` 명령을 다시 실행해줘야 합니다.)

### 4-3. 필요한 패키지 설치하기

```bash
pip install -r requirements.txt
```

몇 분 정도 걸릴 수 있습니다. 설치가 끝나면 준비 완료입니다.

## 5. 실행 방법

### 5-1. (가장 먼저 해볼 것) 웹 대시보드 실행하기

```bash
streamlit run app.py
```

실행하면 자동으로 웹 브라우저가 열리면서 대시보드가 나타납니다.
(자동으로 안 열리면 터미널에 나오는 `Local URL: http://localhost:8501` 주소를 복사해서
직접 브라우저 주소창에 붙여넣으세요.)

대시보드에서 할 수 있는 것:

1. **왼쪽 사이드바에서 종목 검색** — 시장(KOSPI/KOSDAQ) 선택 후 종목명이나 코드로 검색
2. **"가격 차트 & 지표" 탭** — 캔들차트, 이동평균선, 볼린저밴드, 거래량, RSI, MACD 확인
3. **"현재 시그널" 탭** — 오늘(가장 최근 거래일) 기준으로 어떤 매매 시그널이 떴는지 확인
4. **"과거 시그널 통계" 탭** — 이 종목에서 과거에 같은 시그널이 떴을 때 평균적으로 며칠 뒤 얼마나 올랐는지/내렸는지 확인

처음 어떤 종목을 조회하면 인터넷에서 5년치 데이터를 받아오느라 몇 초~수십 초 정도 걸릴 수 있습니다.
(한 번 받은 데이터는 `data/raw/` 폴더에 저장되어서, 다음에 같은 종목을 볼 때는 훨씬 빠릅니다.)

종료하려면 터미널에서 `Ctrl + C` 를 누르세요.

### 5-2. (선택) 여러 종목을 한꺼번에 분석해서 "시장 전체" 통계 만들기

대시보드의 "과거 시그널 통계" 탭에는 **이 종목 하나만의 통계**뿐 아니라,
**여러 종목을 합친 시장 전체 통계**도 참고용으로 함께 보여줄 수 있습니다.
이 시장 전체 통계를 만들려면 아래 스크립트를 먼저 실행해야 합니다.

```bash
# 연습 삼아 KOSPI 30개 종목만 빠르게 돌려보기 (몇 분 이내)
python scripts/run_backtest.py --market KOSPI --limit 30
```

익숙해지면 범위를 넓혀서 실행할 수 있습니다.

```bash
# KOSPI 전체
python scripts/run_backtest.py --market KOSPI

# KOSPI + KOSDAQ 전체 (종목 수가 많아 꽤 오래 걸립니다 - 종목당 수 초 소요)
python scripts/run_backtest.py --market ALL
```

실행이 끝나면 아래 두 파일이 생성됩니다.

- `data/processed/signal_stats.csv` — 시그널(및 시그널 조합)별 발생횟수/평균수익률/상승확률/최대낙폭 등 통계
- `data/processed/signal_events.csv` — 어떤 종목이 언제 어떤 시그널이 떴었는지 상세 이력

이 상태에서 다시 `streamlit run app.py`를 실행하면(또는 이미 켜져 있다면 브라우저에서
새로고침하면), "과거 시그널 통계" 탭 하단에 방금 만든 시장 전체 통계가 표에 나타납니다.

자주 쓰는 옵션:

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--market` | `KOSPI`, `KOSDAQ`, `ALL` 중 선택 | `ALL` |
| `--limit` | 테스트할 종목 수 제한 (전체 실행 전에 소규모로 먼저 확인할 때 유용) | 제한 없음 |
| `--years` | 몇 년치 데이터를 사용할지 | `5` |
| `--refresh` | 캐시를 무시하고 시세 데이터를 새로 받아옴 | 사용 안 함 |

### 5-3. 종목 검색식(스크리너) 화면 사용하기

`streamlit run app.py`로 실행한 뒤, **왼쪽 사이드바 맨 위에서 "📡 종목 검색식" 페이지**를
클릭하면 이동합니다. 이 화면은 HTS/MTS의 "조건검색식"처럼, 종목 하나가 아니라
**시장 전체에서 지금 조건에 맞는 종목을 찾아주는** 화면입니다. 탭이 두 개 있습니다.

**🔎 종목 검색식 스캔 탭**

1. 시장(전체/KOSPI/KOSDAQ)과 스캔할 종목 수를 정합니다. (처음엔 50~100개 정도로 작게 시작해보세요)
2. 실행할 검색식을 고릅니다 (기본은 6개 전부 선택됨).
3. **"검색 실행"** 버튼을 누르면 진행 상황 표시줄이 뜨면서 종목을 하나씩 확인하고,
   끝나면 검색식별로 조건을 만족한 종목 목록이 표로 나타납니다.

기본으로 들어있는 6개 검색식:

| 검색식 | 설명 |
|---|---|
| 월봉 10선 돌파 후 안착 | 최근 12개월간 월봉 10이동평균선을 못 넘다가, 지난달 거래량을 동반하며(평소 대비 2.5배 이상) 돌파한 뒤 이번 달에도 그 위에 머물러 있는 종목 |
| 정배열 종목 | 5일선 > 20일선 > 60일선 > 120일선 순서로 정렬된 종목 (상승 추세가 여러 기간에 걸쳐 일관될 때) |
| 눌림목 매수 | 상승추세(종가>60일선, 20일선>60일선)를 유지한 채 20일선까지 눌렸다가 다시 20일선 위로 반등한 종목 |
| 이격도 과열/침체 | 종가가 20일선보다 지나치게 높거나(과열, 115% 이상) 낮은(침체, 88% 이하) 종목 |
| 박스권 돌파 | 최근 20거래일 동안 좁게(10% 이내) 횡보하다가 거래량을 동반해 박스 상단을 오늘 돌파한 종목 |
| 거래량 바닥 다지기 후 급증 | 거래량이 한동안 잠잠하다가(20일 평균이 60일 평균의 60% 이하) 오늘 갑자기 터지면서(20일 평균의 3배 이상) 주가도 오른 종목 |

이 조건들의 정확한 기준값은 전부 `src/config.py`에 있으니, 원하는 대로 숫자를 바꿔볼 수 있습니다.

**💰 거래대금 순위 (기관/외국인) 탭**

최근 N일 동안 기관 또는 외국인이 가장 많이 순매수(매수 - 매도 거래대금)한 종목 순위를
보여줍니다. 이 데이터는 한국거래소(KRX) 투자자별 매매 데이터라서, 이 프로젝트의 다른
부분과 달리 [`pykrx`](https://github.com/sharebook-kr/pykrx) 라이브러리로 가져옵니다.
시장/투자자 구분/조회 기간/표시 종목 수를 고르고 **"순매수 순위 조회"** 버튼을 누르면 됩니다.

> ⚠️ 검색식 스캔은 종목마다 시세를 확인해야 해서 처음 실행할 때는 시간이 걸립니다.
> 한 번 조회한 종목은 `data/raw/`에 캐시되어 다음번엔 훨씬 빨라집니다. 스캔한 종목 수가
> 많을수록 느려지므로, 처음엔 적은 수로 테스트해보고 점점 늘려가세요.

## 6. 어떤 지표/시그널을 계산하나요?

### 계산하는 기술적 지표

- 이동평균: 5일 / 20일 / 60일 / 120일 / 200일
- RSI(14)
- MACD (12, 26, 9)
- 볼린저밴드 (20일, ±2 표준편차)
- 거래량 20일 이동평균
- 52주(약 252거래일) 신고가 대비 현재가 비율
- 20일 / 60일 모멘텀 (N일 전 대비 수익률)

### 정의된 매매 시그널

| 시그널 | 의미 |
|---|---|
| `golden_cross_20_60` | 20일 이동평균이 60일 이동평균을 아래에서 위로 돌파 (골든크로스) |
| `volume_spike_2x` | 거래량이 20일 평균 거래량의 2배 이상 |
| `breakout_60d_high` | 최근 60거래일(오늘 제외) 최고 종가를 오늘 종가가 돌파 |
| `rsi_cross_up_50` | RSI(14)가 50을 아래에서 위로 돌파 |

새로운 시그널을 추가하고 싶다면 `src/signals.py`에 함수를 하나 추가하고
`SIGNAL_FUNCS` 딕셔너리에 등록하면, `backtest.py`와 `app.py`가 자동으로 인식합니다.

### 시그널별로 계산하는 통계

각 시그널(그리고 2~3개씩 묶은 조합)에 대해, 시그널 발생 후 5 / 20 / 60거래일 뒤 기준으로:

- 발생 횟수
- 평균 수익률 / 중앙값 수익률
- 상승 확률 (수익률 > 0 인 비율)
- +10% 이상 상승 확률
- 평균 최대 낙폭 (보유 기간 중 가장 많이 빠졌을 때의 평균)
- **baseline 대비 초과수익(excess_return)과 p-value** — 아래 7-1절 참고
- **거래비용을 뺀 순수익률/순승률(net_mean_return, net_win_rate)**
- **표본수/p-value를 종합한 신뢰도 라벨(confidence)**

## 6-1. "이거 실전에서 믿고 써도 돼?" — 신뢰도 검증 기능

처음 버전은 "시그널이 뜬 뒤 평균적으로 얼마나 올랐다"는 숫자만 보여줬는데, 그것만으로는
그 숫자가 우연인지 진짜 의미가 있는지 알 수 없습니다. 그래서 아래 기능을 추가했습니다.

1. **통계적 유의성 검정(p-value)** — "시그널이 뜬 날의 수익률"을 "그냥 아무 날(baseline)"의
   수익률과 통계적으로 비교합니다(Welch's t-test). `pvalue`가 0.05보다 작으면 우연이라고
   보기 어려운 수준의 차이, 0.05~0.1이면 약한 근거, 0.1 이상이면 그냥 우연일 가능성이 높습니다.
2. **최소 표본수 경고** — 발생 횟수가 `config.MIN_SAMPLE_SIZE`(기본 30회) 미만이면 아무리
   평균 수익률이 좋아 보여도 `confidence` 컬럼에 **"표본부족"**이라고 표시됩니다. 이건 통계를
   신뢰하기 어렵다는 뜻이니 무시하지 마세요.
3. **거래비용 반영** — 매수·매도 수수료와 증권거래세를 대략치(왕복 약 0.3%,
   `config.ROUND_TRIP_COST_PCT`)로 가정해서, 이를 뺀 `net_mean_return`(순수익률)도 같이
   보여줍니다. 통계상 수익률이 양수여도 순수익률이 거의 0이거나 음수면 실전에서는 남는 게
   없다는 뜻입니다.
4. **시장 추세(상승장/하락장) 필터** — 같은 시그널이라도 코스피/코스닥 지수 자체가
   상승 추세(지수가 200일 이동평균 위)일 때와 하락 추세일 때 성과가 다를 수 있습니다.
   대시보드의 "시장 추세별 통계"에서 이 둘을 나눠서 확인할 수 있습니다.

대시보드의 "과거 시그널 통계" 탭 맨 위에 있는 **"이 통계, 어떻게 읽어야 하나요?"** 를 펼치면
이 내용이 화면에서도 간단히 요약되어 있습니다.

> ⚠️ 그래도 이건 여전히 **참고용 리서치 도구**입니다. p-value가 낮고 표본이 충분해도, 그건
> "과거 데이터 안에서" 유의미했다는 뜻일 뿐, 미래에도 똑같이 작동한다는 보장은 없습니다.
> 특히 표본이 소수 종목/짧은 기간에 몰려있다면 과최적화(overfitting)일 수 있으니, 여러
> 종목·여러 기간에 걸쳐 일관되게 나오는 패턴인지 직접 확인하고 판단하세요. 실제 매매는
> 본인 책임입니다.

## 7. Look-ahead bias(미래 데이터 유출)를 어떻게 막았나요?

**Look-ahead bias**란, 과거 시점의 분석에 원래는 그 시점에 알 수 없었던 미래 정보가
몰래 섞여 들어가서, 실제로는 불가능한 "완벽한 예측"처럼 통계가 부풀려지는 문제입니다.
이 프로젝트에서는 다음 원칙으로 이를 방지합니다.

1. **지표 계산(`src/indicators.py`)** — 이동평균/RSI/MACD/볼린저밴드 등은 전부
   `rolling()`, `ewm()`, `shift(양수)` 처럼 "현재 시점까지의 과거 데이터만" 사용하는
   pandas 연산만 사용합니다. 구조적으로 미래 값이 섞일 수 없습니다.
2. **시그널 판정(`src/signals.py`)** — 오직 위 지표들(t 시점까지 계산된 값)만 사용해서
   판정합니다. 미래 종가나 미래 수익률은 절대 시그널 판정에 쓰이지 않습니다.
3. **미래 수익률(`src/backtest.py`)** — "시그널이 뜬 뒤 실제로 며칠 후 얼마나 올랐는가"는
   당연히 미래 데이터를 사용해서 계산하지만, 이 값은 **다른 지표나 시그널을 계산하는
   입력으로 절대 재사용되지 않고**, 오직 "그 시그널이 과거에 유효했는지"를 사후에
   평가하는 결과값(라벨)으로만 쓰입니다.
4. **데이터 끝부분 처리** — 예를 들어 60거래일 뒤 수익률을 계산할 때, 데이터의
   마지막 60거래일 구간은 미래 데이터가 아직 존재하지 않으므로 자동으로 `NaN`(결측치)
   처리되고, 통계 집계 시 제외됩니다.

이 로직은 `synthetic` 데이터로 "미래 가격을 크게 조작해도 과거 시점의 지표/시그널 값이
전혀 바뀌지 않는다"는 것을 자동 검증하는 방식으로 테스트되었습니다.

## 8. 알아두면 좋은 한계점

- **상장폐지된 종목은 포함되지 않습니다.** 현재 상장되어 있는 종목만 대상으로 하기 때문에,
  과거에 상장폐지된(그래서 대부분 손실로 끝났을) 종목들은 통계에서 빠집니다. 이로 인해
  실제보다 통계가 다소 낙관적으로 보일 수 있습니다 (생존 편향, survivorship bias).
- **거래비용(수수료, 세금, 슬리피지)은 반영되지 않습니다.** 통계상의 수익률은 순수 가격
  변화만 반영한 값입니다.
- **ETF, 스팩(SPAC), 우선주 등도 종목 목록에 함께 포함될 수 있습니다.** 일반 보통주만
  보고 싶다면 종목 목록을 필터링하는 로직을 `src/data_loader.py`에 추가해서 커스터마이징할 수 있습니다.
- 시세 데이터는 FinanceDataReader가 제공하는 데이터에 의존하며, 정확성/최신성을 100% 보장하지 않습니다.

## 9. 자주 발생하는 문제 (트러블슈팅)

**Q. `streamlit: command not found` 또는 `ModuleNotFoundError` 가 떠요.**
→ 가상환경이 켜져 있지 않을 가능성이 높습니다. 터미널 맨 앞에 `(.venv)`가 보이는지 확인하고,
안 보이면 4-2단계의 `activate` 명령을 다시 실행한 뒤, `pip install -r requirements.txt`를
다시 실행해보세요.

**Q. 종목을 선택했는데 "데이터를 불러올 수 없습니다" / 네트워크 오류가 나요.**
→ 인터넷 연결을 확인해주세요. 사내망, VPN, 일부 회사/학교 네트워크나 폐쇄된 개발
샌드박스에서는 증권 시세를 제공하는 외부 사이트 접속이 막혀 있을 수 있습니다. 이 경우
일반 가정용/개인 인터넷 환경에서 다시 시도해보세요.

**Q. `python scripts/run_backtest.py --market ALL` 이 너무 오래 걸려요.**
→ 정상입니다. 전체 종목(수천 개)을 순서대로 받아오기 때문에 시간이 오래 걸립니다.
`--limit 50` 처럼 종목 수를 제한해서 먼저 테스트해보고, 익숙해지면 범위를 넓히는 것을
추천합니다.

**Q. 데이터를 최신으로 다시 받고 싶어요.**
→ `data/raw/` 폴더 안의 해당 종목 CSV 파일을 지우거나, `--refresh` 옵션을 사용하세요.
  (대시보드는 껐다 켜면 다시 최신 데이터를 시도합니다. 단, 이미 캐시가 있으면 캐시를
  우선 사용하므로, 완전히 새로 받고 싶다면 `data/raw/` 안의 해당 종목 파일을 지워주세요.)
