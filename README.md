# 나의 주식 차트 (MU, 최근 2년)

공개 시세로 캔들 차트, 20·60일 이동평균, RSI(14)를 그리고 이동평균 교차 전략을 백테스트하는 개인용 웹앱입니다.
교육용 예시입니다. **수익을 약속하지 않으며, 실제 주문 기능은 없습니다.**

## 실행 (초보자용)

1. [Node.js](https://nodejs.org) 18 이상을 설치합니다. 터미널에서 `node -v`로 확인할 수 있습니다.
2. 이 폴더에서 터미널을 열고 실행합니다. 설치할 패키지는 없습니다.
   ```bash
   npm start
   ```
3. 터미널에 나온 주소(기본 `http://localhost:4173`)를 브라우저로 엽니다.
   4173 포트가 사용 중이면 4174, 4175… 순서로 자동으로 다른 포트를 씁니다. 포트를 직접 정하려면 `PORT=5000 npm start`(Windows PowerShell: `$env:PORT=5000; npm start`)를 씁니다.

**종료:** 서버를 실행한 터미널에서 `Ctrl + C`를 누릅니다.

## 종목 바꾸기

- 위쪽 입력칸에 종목 코드(예: `AAPL`, `NVDA`, 한국 주식은 `005930.KS`)를 넣고 **조회**를 누릅니다.
- 주소창에 `?symbol=AAPL`을 붙여 열어도 됩니다.
- **☆ 관심**을 누르면 왼쪽 관심종목에 저장됩니다. 저장 위치는 이 브라우저뿐입니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 캔들 차트 | 일·주·월 전환. 휠로 확대·축소, 드래그로 이동, 더블클릭으로 전체 보기. 마우스를 올리면 시·고·저·종과 지표 값을 보여줍니다. |
| 지표 | MA20, MA60, RSI(14, Wilder 방식), 거래량. 체크박스로 켜고 끕니다. 주·월봉에서는 해당 봉 기준으로 계산합니다. |
| 데이터 출처 | 차트 아래에 출처 링크, 마지막 봉 날짜, 조회 시각을 표시합니다. Yahoo Finance 공개 차트 API를 먼저 쓰고, 실패하면 Stooq CSV를 씁니다. |
| 조회 실패 | 두 출처가 모두 실패하면 오류와 원인을 보여줍니다. **가짜 시세로 대체하지 않습니다.** |
| CSV | 차트 데이터(OHLCV+지표)와 거래 내역을 CSV로 내려받습니다. 파일 첫 줄들(`#`)에 출처와 조회 시각이 들어갑니다. |
| 백테스트 | MA20/60 교차, 아래 규칙 참고. |

## 백테스트 규칙

- 신호는 그날 **종가**까지의 데이터로만 계산합니다. 단기선이 장기선을 상향 돌파하면 매수, 하향 돌파하면 매도 신호입니다.
- 체결은 **다음 거래일 시가**에 합니다. 매수가는 시가×(1+슬리피지), 매도가는 시가×(1−슬리피지)입니다.
- 기본 비용은 수수료 0.1%, 슬리피지 0.05%이며 매수와 매도에 각각 적용합니다. 화면에서 바꿀 수 있습니다.
- 처음 100봉은 지표 준비 구간이라 평가에서 뺍니다. 나머지를 시간순으로 **학습(조정) 70% / 검증 30%**로 나눕니다(60/80%로 변경 가능).
- 구간마다 현금으로 시작하고, 구간 마지막 날 종가에 비용을 반영해 청산했다고 가정합니다. 같은 구간을 단순 보유(첫날 시가 매수, 마지막 날 종가 매도, 같은 비용)한 결과와 비교합니다.
- 파라미터 탐색은 학습 구간 데이터만 씁니다. 고른 값의 검증 구간 결과를 따로 보여줍니다.
- 세금, 환전, 배당, 체결 불가 상황은 반영하지 않습니다.

## 테스트

```bash
npm test
```

지표 계산, 다음 봉 시가 체결, 비용 계산, 미래 데이터 미사용(이후 데이터를 바꿔도 이전 결과가 같은지), 학습 구간 전용 최적화를 확인합니다. 테스트는 합성 데이터만 쓰며, 앱 자체는 합성 데이터를 쓰지 않습니다.
